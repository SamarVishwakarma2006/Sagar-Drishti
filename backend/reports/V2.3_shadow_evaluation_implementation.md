### GATE 2 — Worker Lifecycle & Process Safety
- **Worker Pool Architecture**:
  - Exactly 2 background worker threads (`MAX_SHADOW_WORKERS = 2`) process tasks from the bounded queue.
  - All worker threads are instantiated with `daemon=True`, guaranteeing that shadow processing cannot block application shutdown or cause process hangs.
- **Exception Resilience & Queue Unblocking**:
  - The worker loop executes tasks within a nested `try...finally` structure:
    ```python
    try:
        cls.evaluate_shadow(**task)
    except Exception as e:
        logger.warning("Shadow worker task error: %s", e)
    finally:
        cls._queue.task_done()
    ```
  - Even if an unhandled runtime error or hardware matrix fault occurs during inference, `cls._queue.task_done()` is guaranteed to execute, preventing queue deadlocks or task accounting desynchronization.
- **Self-Healing Thread Pool**:
  - `_start_workers()` inspects existing threads via `[t for t in cls._worker_threads if t.is_alive()]`. If a worker thread is terminated unexpectedly, replacement daemon threads are automatically spawned on the next dispatch.
- **Shutdown Behavior**:
  - On application termination, pending shadow jobs in the queue are safely discarded without disrupting production shutdown.

### GATE 3 — Queue Saturation & Memory Bounding
- **Strict Bounded Queue**:
  - Implemented via standard library `queue.Queue(maxsize=100)`.
  - There are **no hidden unbounded queues, buffers, or background executors** between `PredictionService` and `ShadowV23Service`.
- **Non-Blocking Dispatch & Immediate Job-Shedding**:
  - `dispatch_shadow_evaluation(...)` calls `cls._queue.put_nowait(task)`.
